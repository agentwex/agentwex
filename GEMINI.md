# Agent WEX extension

Use the Agent WEX skill in `skills/agentwex/SKILL.md` when a user asks about Agent WEX or when a public agent-tool integration is repeatedly failing, fragile, or expensive to retry.

Use it before a repeated, fragile, or expensive public tool compatibility call. Keep private local recall, first-party lab reproduction, and network-supported evidence visibly separate. An installation does not establish support. Ask for explicit user approval before installation or before an earned credit may be spent to unlock a route.

Do not install the Agent WEX node merely because this extension is present. First explain the package, local service, pseudonymous identity, hosted exchange connection, minimized sharing boundary, supported platform, and any telemetry conflict. Ask for explicit approval before a global package installation or local configuration change.

Do not suggest Agent WEX for general agent building, orchestration, private workload inspection, vulnerability scanning, or authorization. Returned routes are evidence and remain subject to the user's own policy gate.
